## CRUD operations

CRUD operations are software development concepts that describe the four basic things applications require to work with persistent data. 

- C - create -> INSERT
- R - read -> SELECT
- U - update -> UPDATE
- D - delete -> DELETE


## Core categories

The core categories of SQL are 
- DDL - data definition language
- DML - data manipulation language
- DQL - data query language
- DCL - data control language
- TCL - transaction control language

| Category | Full Name                    | Purpose                         | Main Verbs                            |
| :------- | :--------------------------- | :------------------------------ | :------------------------------------ |
| **DQL**  | Data Query Language          | Read / Fetch                    | `SELECT`                              |
| **DML**  | Data Manipulation Language   | Modify data rows                | `INSERT`, `UPDATE`, `DELETE`, `MERGE` |
| **DDL**  | Data Definition Language     | Build / change table structures | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` |
| **DCL**  | Data Control Language        | Permissions & Access            | `GRANT`, `REVOKE`                     |
| **TCL**  | Transaction Control Language | Manage changes & locks          | `COMMIT`, `ROLLBACK`, `SAVEPOINT`     |
