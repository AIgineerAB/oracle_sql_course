This course focuses on Oracle SQL and PL/SQL which stands for Procedural Language extension to Structured Query Language (SQL). It is used in Oracle databases such as oracle26ai that we use in this course. However you can use either a newer one or an older one. 

For this course we'll use a Linux machine and podman to run oracle26ai as a cointainer, so it is good to have some basic knowledge of working with the command line and a shell such as bash.
